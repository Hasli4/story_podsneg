# «Подснежник» — веб-версия визуальной новеллы

Проект уже экспортирован из Tyrano Builder в TyranoScript — движок работает целиком в браузере на HTML, CSS и JavaScript. Публикуемая версия — точный веб-экспорт Builder в [`Podsneg_HTML`](Podsneg_HTML/): сценарий, ветвления, изображения, видео, музыка, меню, журнал и сохранения не переписаны и не упрощены.

В исходном HTML-экспорте Builder отсутствовал один пустой служебный файл `data/scenario/system/chara_layer_define.ks`, на который ссылается стартовый сценарий. Он добавлен с оригинальной служебной строкой; на сюжет, диалоги и визуальную часть это не влияет, но предотвращает ошибку запуска.

Откройте корневой `index.html` через веб-сервер или опубликуйте репозиторий: он перенаправляет игрока к браузерной версии в `Podsneg_HTML/`.

## Публикация на GitHub Pages

1. Создайте пустой репозиторий на GitHub и отправьте туда содержимое этой папки. В `.gitignore` уже исключены Windows-сборка `Podsneg-win32-x64`, рабочие исходники `новелла` и прежний дубликат `Podsneg`; для сайта нужен только `Podsneg_HTML`.
2. В репозитории откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, затем ветку `main` и папку **/(root)**, после чего нажмите **Save**.
4. Дождитесь публикации и откройте URL, который покажет GitHub. Корневой адрес запускает новеллу автоматически.

Файл `.nojekyll` обязателен: без него GitHub Pages может не отдать служебные сценарии Tyrano с именами `_scene1.ks`, `_lineyka.ks` и т. п. Сохранения остаются локальными в браузере игрока (Web Storage), как и в исходной веб-версии Tyrano.

## Локальный запуск

Не открывайте HTML двойным кликом: движок подгружает сценарии, а браузеры блокируют такие запросы с `file://`. В PowerShell из корня проекта можно запустить:

```powershell
npm run serve
```

Затем откройте [http://localhost:8080](http://localhost:8080). Остановить сервер можно сочетанием `Ctrl+C`.

Для быстрой проверки состава веб-сборки выполните `npm run check`. Node.js нужен только для локального предпросмотра и этой проверки — на GitHub Pages никакой сборки, Node.js или серверной части нет.

## Структура

- `index.html` — точка входа GitHub Pages.
- `Podsneg_HTML/` — самостоятельная HTML-новелла и все используемые ею ресурсы; это папка для GitHub Pages.
- `Podsneg_HTML/data/scenario/` — сценарии TyranoScript с диалогами и выборами.
- `Podsneg_HTML/data/bgimage/`, `fgimage/`, `bgm/`, `sound/`, `video/` — графика и аудио.
- `Podsneg/`, `Podsneg-win32-x64/`, `новелла/` — рабочие/настольные копии, сохранённые локально, но не включаемые в публикацию.

Тираноскрипт поддерживает полноценную браузерную публикацию: по официальной инструкции для веб-версии достаточно разместить весь каталог проекта на сервере. [Официальная документация TyranoScript](https://tyrano.jp/usage/tutorial/complete)
